# NGTXC_RollaLie


# How To Play:
1. Go to [Releases](https://github.com/Fooisntcat/NGTXC_RollaLie/releases) and download the latest version of the Build.zip file
2. Extract the .zip
3. Run the .exe
4. Have fun!

# Notes:
1. You need to have 2 glasses of TiltFive since this is a local multiplayer game.
2. If you don't have TiltFive device, use Q and E to roll for player 1 and 2 respectively.
